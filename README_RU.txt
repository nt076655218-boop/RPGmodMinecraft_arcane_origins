КАК ПОЛУЧИТЬ ГОТОВЫЙ .JAR (2 ПРОСТЫХ СПОСОБА):

СПОСОБ 1 — На своём ПК в один клик (Windows):
1. Убедись, что у тебя стоит Java 21 (JDK 21). Скачать можно с https://adoptium.net/
2. Распакуй весь архив в любую папку (желательно без русских букв в пути, например C:\Mods\ArcaneOrigins).
3. Просто дважды кликни по файлу BUILD_MOD.bat.
4. Через пару минут рядом с ним появится готовый файл arcaneorigins-0.1.0.jar — кидай его в папку mods (NeoForge 1.21.1)!

СПОСОБ 2 — Через GitHub вообще без программ на ПК:
1. Создай новый репозиторий на github.com и загрузи туда все файлы из архива.
2. Открой вкладку "Actions" -> "Build Arcane Origins JAR" -> нажми "Run workflow".
3. Когда загорится зелёная галочка, скачай готовый .jar в разделе "Artifacts".

УПРАВЛЕНИЕ В ИГРЕ:
- При первом заходе в мир само откроется меню выбора класса и подкласса.
- [R] — Применить активное заклинание (также работает ПКМ с Книгой Заклинаний или Посохом).
- [V] — Переключить активное заклинание (Лёд / Молния).
- [G] — Открыть меню персонажа (просмотр пассивок или повторный выбор, если ещё не выбран).

КОМАНДЫ ДЛЯ ТЕСТОВ (нужны читы / права админа):
- /arcane unlock_sorcerer  — разблокировать редкий класс Чародея (обычный шанс 10% при первом входе)
- /arcane reset            — сбросить класс и открыть меню заново
- /arcane mana             — мгновенно восстановить всю ману
